# E-commerce Fake Review Detection and Summarization

**Self Project** | *May'25--Jun'25*

## Project Overview

A comprehensive machine learning project focused on detecting fake reviews in e-commerce platforms and generating summaries of authentic reviews using advanced NLP techniques.

## Key Achievements

1) Performed **EDA** with **visuals, polarity, POS tags**, and engineered features using **TF-IDF, stylometry, lexical traits**

2) Achieved **accuracy of 93%** using **DistilBERT**, outperforming **SVM, Random Forest, LSTM, Calibrated Ensemble**

3) **Fine-tuned T5, BART**, with T5 getting better metrics **ROUGE-1: 0.66, ROUGE-2: 0.59, ROUGE-L: 0.63, BLEU: 0.54**

## Tech Stack

- **Machine Learning**: DistilBERT, T5, BART, SVM, Random Forest, LSTM, Calibrated Ensemble
- **NLP**: TF-IDF, POS tagging, stylometry, lexical analysis
- **Data Analysis**: Pandas, NumPy, Matplotlib, Seaborn
- **Deep Learning**: Transformers, Hugging Face
- **Evaluation**: ROUGE, BLEU, accuracy metrics
